# 5020 文字截断排查与通用修复

样本：`U2/批次/A33Z2202506001/S22C-726080515020.pdf`，源文件 78 页。

## 根因

- 空单元格的高零宽 `rule` 把同行文字基线抬高，造成顶部留白和底部溢出。
- 不可分页的顶层表格、旋转面板没有按页面可用空间适配。
- 固定高度 `minipage` / `parbox` 声明的高度小于实际内容，外层尺寸检查低估真实高度。
- 并排面板的基线不同，分别适配仍可能在合并时超过页高。
- Latin Modern 缺少圈号 1-10 和实心圆字符的字形，编译成功仍会缺字。

## 修复范围

`page_layout.py` 在整份本地优化阶段统一处理：空白单元格的行高向基线下方延伸；固定高度框按实际内容扩展；顶层面板按可用宽高等比适配并统一顶部对齐；表单圈号和实心圆交给 CJK 字体显示。嵌套面板不重复缩放。

保留字段 ID、字段值和源页顺序，不调用模型。优化版本更新使旧优化缓存失效，识别与协调的有效缓存继续复用。

## 验证与限制

真实 XeLaTeX 回归测试覆盖高表格、空单元格高占位、固定高度框、旋转面板、不同基线的并排面板及圈号字形。全量回放检查字段 payload 一致性、幂等性、源页映射、横竖纸张尺寸和字符边界，并渲染关键页及整份缩略图。

在 70-78 页重识别后的样本上，本轮本地回放从 94 个输出页变为 79 页；保留全部 1902 个 `fieldvalue` payload（含嵌套，非唯一字段数），未检测到页面外字符或错误纸张尺寸，也不再出现缺字警告。源第 12 页仍自然溢出为两页，页数差异只记录提示。

这不是识别内容修复。源图表中已被识别 TEX 省略的曲线不会由排版规则恢复，部分表格边线和页眉布局仍有识别遗留问题。边界检查也不能证明内容与扫描原件逐字一致，应结合渲染对照和后续人工核对。
